# Лабораторные работы по курсу Java

Учебный репозиторий с выполненными практическими заданиями по изучению синтаксиса и стандартных библиотек по дисциплине **"Язык программирования Java"** в СПбПУ.

## 🛠 Технологии и инструменты
* **Язык:** Java 17+
* **Среда разработки:** IntelliJ IDEA

---

## Разобранные темы и выполненные задания

В рамках данного курса реализованы примеры кода, покрывающие следующие концепции:

### 1. Обработка исключений (Exceptions)
* **Конструкции `try-finally`:** Особенности работы без блока `catch` и ограничения синтаксиса (недопустимость нескольких `finally`).
* **Multi-catch и иерархия исключений:** Одинаковая обработка нескольких независимых ошибок и правильное построение цепочки `catch`-блоков от наследников к родителям.
* **Неизменяемость параметров:** Использование модификатора `final` в блоках `catch` для защиты от подмены объекта исключения.
* **Кастомные исключения:** Создание собственных классов-наследников от `Exception` с реализацией стандартных конструкторов (включая механизм *Exception Chaining*).

### 2. Система ввода-вывода (Java I/O)
* **Байтовые потоки:** Демонстрация работы методов `read()` и `write(int)` на базе абстрактных классов `InputStream` и `OutputStream` (использование `ByteArrayInputStream` и `ByteArrayOutputStream`).
* **Управление ресурсами:** Реализация собственного ресурса с интерфейсом `AutoCloseable` для демонстрации работы конструкции `try-with-resources`.
* **Символьные потоки (`Reader` / `Writer`):** Решение проблемы мультибайтовых кодировок и символов (Unicode) при чтении текстовых данных.
* **Парсинг файлов:** Использование класса `java.util.Scanner` для извлечения различных типов данных (числа, строки) из текстовых файлов с обработкой `FileNotFoundException`.
